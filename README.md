# Anas Weds Maria — Wedding Invitation (Next.js)

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Add Your Images

Place these images in `/public/images/`:

| Filename                  | Used In          |
|---------------------------|------------------|
| `cover-image.jpeg`        | Hero section     |
| `grand-hayat-front.webp`  | Mehndi event     |
| `event-barat.jpg`         | Barat event      |
| `gallery-1.jpg`           | Gallery          |
| `gallery-3.jpg`           | Gallery          |
| `gallery-4.jpg`           | Gallery          |
| `gallery-6.jpg`           | Gallery          |
| `gallery-7.jpg`           | Gallery          |

Also place `og-image.jpg` in `/public/` for social sharing.

Copy them from your existing Netlify deployment or source folder.

## Audio

Both songs are already included in `/public/audio/`:
- `o-maahi.mp3` — O Maahi (Dunki)
- `satranga.mp3` — Satranga (Animal)

## Deploy to Netlify

```bash
npm run build
```

Then deploy the `.next` output or connect your GitHub repo to Netlify.
